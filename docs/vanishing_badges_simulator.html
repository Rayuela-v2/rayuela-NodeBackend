Manual Adaptation Operations

Definition 3.1: Estimated Awarding Time (ET_b) Effort Metric
ET_b = (1 / |U_b|) * Σ_{u ∈ U_b} contributions(u at award time)

Calculates the average number of contributions earned players had completed when they were awarded badge b. In §4.3, this determines the expiration window length.

Definition 3.2: Individual Interest [i3(p, b)] Recency Metric
i3(p, b) = 1 / (now - t0(p, b))  [if achievable, else 1.0]

t0(p, b) is the day player p unlocked all prerequisites for badge b. If a long time has elapsed without earning b, i3 → 0 indicating abandonment.

Definition 3.3: Community Interest [CII(b)] Ranking Metric
CII(b) = median( { i3(p, b) : p ∈ ep(b) } )

Median of individual interest across all eligible players ep(b). Low CII(b) identifies badges that players have unlocked but are neglecting.

Definitions 3.4 & 3.5: PMI, relPMI & CMI Trigger Metric
PMI(p) = |{ s : cnum(p,s) ≥ cnum(p,prev(s)) ≠ 0 }|
relPMI(p) = PMI(p) / avg(PMI)
CMI = median( { relPMI(p) : p ∈ P } )

Measures period-over-period engagement growth momentum. CMI is the median relative motivation of the community and serves as the global adaptation trigger.
